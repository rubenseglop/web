# Web de ejemplo

Web de presentación responsive creada con HTML, CSS y JavaScript puro. No necesita backend, compilación ni dependencias para ejecutarse.

## Verla en local

Abre `index.html` en el navegador.

## Publicarla con GitHub Pages

1. Entra en **Settings → Pages** del repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**.
4. Pulsa **Save**.

La dirección será:

https://rubenseglop.github.io/web/

Los cambios que hagas en `index.html` se publicarán al actualizar la rama seleccionada.
